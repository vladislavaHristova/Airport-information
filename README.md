Airport Information System

1.Описание
  - система за информация за полети с възможност за резервация.

2. Технологии
   - ASP.NET Core MVC
   - Entity Framework Core
   - SQL Server LocalDB
   - NUnit

3. Архитектура - трислойна архитектура и MVC шаблон

4. Функционалности
   - Преглед на всички полети
   - Търсене на полети по дестинация
   - Сортиране на полети по час, авиокомпания, детинация
   - Резервация на полет
